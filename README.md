# Ситуационный центр по транспорту Республики Казахстан

Живой дашборд транспорта Казахстана на открытых данных. Работает как сайт на GitHub Pages, без своего сервера.

## Что на карте

| Слой | Источник | Обновление |
|---|---|---|
| Самолёты (позиции, высота, скорость, коды бедствия) | OpenSky, adsb.lol, adsb.fi (ADS-B) | сервер ~10 мин + браузер раз в минуту |
| Аэропорты: видимость, облачность, ветер, категория VFR/IFR/LIFR | METAR, NOAA aviationweather.gov | ~10 мин |
| Дороги: реальная сеть магистралей, цвет по погоде (гололёд, снег, метель, туман, ветер) | OpenStreetMap + Open-Meteo | геометрия раз в неделю, погода ~30 мин |
| Температура по сетке ~150 точек | Open-Meteo | ~30 мин |
| Железные дороги | OpenRailwayMap | тайлы онлайн |
| Снимок со спутника за вчера (снег, облака) | NASA GIBS, VIIRS | ежедневно |
| Землетрясения M2.5+ за 7 дней | USGS | ~10 мин |
| Суда на Каспии | aisstream.io (нужен ключ) | ~10 мин |
| Пробки | Google (неофициально), TomTom (ключ) | онлайн |
| Трубопроводы, пункты пропуска, порты | схема | — |
| Ещё ~60 подложек и слоёв | см. раздел ниже | — |

Клик по любому объекту открывает подробности справа; вкладки сверху панели — отрасли.

## Подложки и слои (панель слева)

- **Подложки:** тёмная и светлая схемы Esri, OpenStreetMap, OSM Humanitarian, CyclOSM, ÖPNVKarte, 2ГИС; Google Карта / Спутник / Гибрид / Рельеф; Esri Спутник, Clarity, Улицы, Топо, National Geographic, Физическая, Отмывка рельефа, Terrain, Океан; OpenTopoMap, EOX Terrain; Sentinel-2 без облаков, NASA VIIRS и MODIS за выбранную дату, Black Marble, Blue Marble; с ключом — CARTO, Thunderforest, Stadia/Stamen.
- **Слои:** живые данные страницы; погода и климат (радар RainViewer, NASA: температура поверхности день/ночь, снежный покров, аэрозоль, температура воздуха AIRS, осадки IMERG, температура воды Каспия, ночные огни; с ключом OpenWeatherMap — температура, осадки, облака, ветер, давление); транспорт (OpenRailwayMap: сеть, скорости, электрификация; дороги Esri; дороги и пробки Google; пробки и инциденты TomTom; OpenSeaMap); справочные (границы и подписи Esri, подписи EOX, тени рельефа).
- Для каждого слоя есть ползунок прозрачности. Для снимков NASA выбирается дата; если за неё снимка ещё нет, берётся последний доступный (сервер раз в 6 часов читает список дат из GIBS).
- Google и 2ГИС отдают тайлы без официального API — помечены «неофиц.» и могут отключиться. Ключи вводятся в панели и хранятся только в браузере.
- `scripts/check-tiles.mjs` (workflow «Проверка подложек») раз в неделю запрашивает по тайлу из каждого источника и собирает контрольный лист.

**Важно:** состояние дорог — это оценка по погоде, а не официальные данные КазАвтоЖол. Закрытые источники (КТЖ, МВД, КГД, НОТАМ и др.) перечислены во вкладке «Источники».

## Как это работает

- `.github/workflows/live.yml` — раз в час стартует задача, которая ~55 минут работает в цикле: каждые ~5 минут собирает данные (`scripts/fetch-live.mjs`) и публикует их в ветку `live-data` (одним коммитом, история не растёт). Планировщик GitHub не умеет запускать задачи чаще раза в час, поэтому цикл внутри.
- `.github/workflows/pages.yml` — при каждом изменении `main` публикует сайт на GitHub Pages (в Settings → Pages источник должен быть **GitHub Actions**).
- `.github/workflows/roads.yml` — раз в неделю загружает геометрию дорог из OSM (`scripts/fetch-roads.mjs`) в `data/roads.json`.
- `.github/workflows/check.yml` — ежедневная самопроверка: открывает сайт в headless-браузере, кликает по объектам, пишет отчёт в журнал и прикладывает скриншоты.
- Страница (`index.html`, `assets/`) каждые 5 минут читает данные из ветки `live-data` (через raw.githubusercontent.com), а если та недоступна — из папки `data/` самого сайта.

## Необязательные ключи (Settings → Secrets and variables → Actions)

- `OPENSKY_CLIENT_ID`, `OPENSKY_CLIENT_SECRET` — аккаунт opensky-network.org, больше самолётов и выше лимиты.
- `AISSTREAM_KEY` — бесплатный ключ aisstream.io для судов на Каспии.

## Запуск вручную

Actions → «Живые данные и публикация» → Run workflow. Первый запуск «Геометрия дорог» тоже можно запустить вручную.
